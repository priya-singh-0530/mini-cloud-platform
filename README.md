# Mini Cloud Platform

A responsive cloud deployment dashboard built using Next.js, React, TypeScript, and Tailwind CSS.

## Features

- Dashboard with project overview
- Project listing and status tracking
- Deployment form and deployment details
- Logs and settings pages
- Login and registration pages
- Responsive user interface
- Reusable UI components
- Mock API service layer
- Form validation

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS

## Installation

1. Install Node.js.
2. Open the project folder in VS Code.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## Production Build

Run:

```bash
npm run build
```

## Note

This project uses mock data for demonstration purposes. It does not perform real cloud deployments.
